## 📌 About

This repository contains the source code for my personal portfolio website, created to showcase my development journey, technical skills, selected projects, and professional background.

The website features a modern, space-inspired design with interactive elements, smooth animations, and a responsive layout.

## ✨ Features

- Responsive design for desktop and mobile devices.
- Interactive hero and about sections.
- Dynamic skills showcase with category filtering.
- Project showcase with GitHub and live demo links.
- Dark and light theme support.
- Smooth animations and interactive backgrounds.
- Resume download functionality.
- Contact form integration using EmailJS.

## 🛠️ Built With

- React
- JavaScript (ES6+)
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React
- EmailJS

## ⚙️ Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/sayakroy83/Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.
